# Historical experiments

The French phone demo, original browser-export experiments and their helpers are
retained here for reference. They are not the supported build/deployment interface.
Some scripts intentionally contain old paths and repository names.

Use the root README, `scripts/`, `tests/` and `docs/RUNNING.md` for Kalulu-DE.
The full original Git states and artifact branches are also preserved by the
`archive/tmp/*` tags. Historical generated files remain in those snapshots rather
than being copied into the current source tree.
